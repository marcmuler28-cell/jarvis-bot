📁 ESTRUCTURA DE ARCHIVOS
═══════════════════════════════════════════════════════

1. server.py
   - Servidor Flask + Socket.IO (backend HTTP)
   - Maneja la interfaz web/Electron
   - Ejecuta el bucle de voz (voice_loop)
   - Recibe eventos del botón Walkie-Talkie
   - Puerto: 5000

2. assistant.py (~2200 líneas)
   - Cerebro del asistente (ReActAgent)
   - Procesa comandos de voz usando modelos de IA
   - Conexión con herramientas del sistema
   - Tiene SelfImprover (auto-aprendizaje)
   - Llama a MemoryManager para recordar interacciones
   - ✅ Clasificador contextual con LabelEncoder + RandomForest
     • _predict_context_action() con safe_transform() para etiquetas nuevas
     • Predicción genérica en _fast_path para comandos ambiguos
     • Entrenamiento nocturno con ~/.jarvis/retrain_models.sh
   - ✅ HealthMonitor para métricas de uso y tasa de éxito
   - ✅ FileChangeHandler (watchdog) para monitoreo automático de archivos

3. ui.py
   - Interfaz de voz (VoiceInterface)
   - Escucha micrófono con Faster-Whisper
   - Convierte texto a voz (TTS) con edge-tts + mpv
   - Métodos principales:
     • listen(timeout=4) - Escucha y transcribe
     • speak(texto) - Dice algo en voz alta

4. utils.py
   - Clase SystemTools (todas las herramientas)
   - Métodos para abrir apps, archivos, controlar mouse,
     Spotify, terminal, etc.
   - ✅ Nuevas herramientas nativas Linux:
     • set_brightness, get_brightness (brightnessctl)
     • set_volume, get_volume (pactl)
     • lock_session (loginctl)
     • system_status, pending_updates (pacman)
     • list_processes mejorado (top CPU/RAM)
     • kill_process (con confirmación)
   - ✅ _log_file_event() para registro de historial de archivos

5. database.py
   - Conexión a MySQL (localhost, root/<YOUR_MYSQL_PASSWORD>)
   - Tablas: interactions, lessons, conflict_fixes
   - Guarda memoria del asistente (conversaciones, lecciones)

6. finetune_db.py + finetune_dataset.db
   - Base SQLite para dataset de fine-tuning
   - Tablas: failed_interactions, finetune_dataset
   - Exportable a JSONL (ChatML) para QLoRA

7. normalizer.py
   - Normalizador de texto (tildes, artículos, ruido)
   - Distancia Levenshtein para fuzzy matching
   - Corrige errores de pronunciación ("spotifi" → "spotify")

8. config.py
   - Configuración de modelos de IA
   - Variables de audio (dispositivos, sample rate)
   - MODOS: TEXT_MODE (escribir en terminal) o VOZ

9. main.py
   - Punto de entrada alternativo (sin interfaz web)
   - Arranca asistente completo desde terminal

10. jarvis_ai_voice_interface.html
    - Interfaz gráfica web (HTML+Canvas+Socket.IO)
    - Animación de átomo + HUD
    - Botón "PULSAR PARA HABLAR"

11. ui-electron/
    - Aplicación de escritorio (Electron + React)
    - Carga server.py automáticamente
    - Misma interfaz que el HTML pero como ventana nativa
    - Para construir: cd ui-electron && npm run build

12. planner.py (NUEVO)
    - Planificador por recetas JSON
    - RecipeLoader: carga/guarda/busca recetas en ~/.jarvis/recipes.json
    - ParamExtractor: extrae parámetros con regex
    - PlanExecutor: ejecuta pasos con precondiciones, recuperación y deshacer
    - Archiva recetas no usadas tras 30 días

13. rag.py (NUEVO)
    - Sistema RAG con ChromaDB + Ollama (nomic-embed-text)
    - Indexa documentos y recupera fragmentos relevantes
    - Umbral de similitud dinámico (0.6)

14. context_collector.py (NUEVO)
    - Recolector de contexto para el clasificador
    - get_active_window_kde() → ventana activa via D-Bus
    - log_interaction() → guarda CSV en ~/.jarvis/logs/context_habits.csv

15. health_monitor.py (NUEVO)
    - HealthMonitor: registra métricas de uso
      • total_requests, fast_path_hits, llm_calls
      • llm_total_time, parse_retries
      • actions_executed, actions_failed
    - get_report() → informe de salud

16. ~/.jarvis/retrain_models.sh
    - Script de entrenamiento nocturno del clasificador contextual
    - Lee ~/.jarvis/logs/context_habits.csv
    - Entrena RandomForest con LabelEncoder
    - Guarda modelo en ~/.jarvis/models/context_classifier.pkl
    - ✅ Al terminar, apaga el sistema automáticamente
    - Llamado desde "estudia tus lecciones y apágate"

17. ~/.jarvis/recipes.json
    - Recetas de automatización (organizar escritorio, limpiar descargas, etc.)

18. ~/.jarvis/logs/planner.log
    - Log detallado de ejecución de planes

19. ~/.jarvis/file_history.json
    - Historial de archivos (watchdog + registro manual)

20. ~/.jarvis/task_notifier.sh
    - Script de notificación de tareas próximas (Taskwarrior)

🌐 CÓMO USAR
═══════════════════════════════════════════════════════

1. Iniciar servidor:
   systemctl --user start jarvisbot.service
   (O manual: cd /home/marc/Descargas/JarvisBot && python server.py)

2. Abrir interfaz:
   - Web: http://127.0.0.1:5000  (sirve HTML automáticamente)
   - Electron: cd ui-electron && npm start

3. Modo Walkie-Talkie (único modo):
   - Presiona "PULSAR PARA HABLAR"
   - Habla claro (espera 2-3 segundos procesando)
   - Suelta el botón
   - Jarvis responde en voz alta

4. Ver logs:
   journalctl --user -u jarvisbot.service -f

5. Detener:
   systemctl --user stop jarvisbot.service

🔄 FLUJO DE FUNCIONAMIENTO
═══════════════════════════════════════════════════════

1. Usuario presiona botón → socket.emit('walkie_talkie_start')
2. server.py activa walkie_active = True
3. voice_loop llama a voice.listen(timeout=4)
4. ui.py captura audio con sounddevice
5. faster-whisper transcribe a texto
6. server.py recibe el texto → agent.process(texto)
7. assistant.py (ReActAgent):
   a. normalizer.py corrige errores ("spotifi" → "spotify")
   b. _fast_path() busca comandos directos (sin LLM):
      • Predicción contextual con RandomForest (si aplica)
      • Recetas del planificador (organizar, limpiar, etc.)
      • Herramientas de sistema (brillo, volumen, etc.)
      • Búsqueda en historial de archivos
      • Tareas (Taskwarrior)
      • Spotify, apps, mouse, etc.
      • Si acierta → respuesta instantánea (<0.1s)
   c. Si no acierta fast_path:
      • Busca en conectores externos (RSS, clima, etc.)
      • Si es tarea compleja → planificador por recetas
      • Si es ambiguo → clasificador contextual
   d. Si falla todo: registra en finetune_dataset.db
   e. Qwen 3B/7B procesa con ReAct (Thought→Action→Observation)
8. assistant.py devuelve respuesta + acciones
9. Se registra la interacción en el historial de archivos (si aplica)
10. Se registra en context_habits.csv (para el clasificador)
11. server.py envía respuesta a interfaz (socket)
12. server.py llama a voice.speak(respuesta) → TTS
13. Usuario suelta botón → socket.emit('walkie_talkie_stop')
14. walkie_active = False, vuelve a reposo


🧠 SISTEMA DE APRENDIZAJE CONTINUO
═══════════════════════════════════════════════════════

Durante el día:
- Cada interacción exitosa/fallida se guarda en ~/.jarvis/logs/context_habits.csv
- El asistente registra: hora, día, ventana activa, comando, acción tomada, éxito
- Las preferencias se guardan como lecciones en la base de datos

Por la noche:
- Al decir "estudia tus lecciones y apágate":
  1. Se ejecuta ~/.jarvis/retrain_models.sh
  2. Entrena un RandomForest con los datos del día
  3. Guarda el modelo en ~/.jarvis/models/context_classifier.pkl
  4. Apaga el sistema automáticamente
- Al día siguiente, el asistente arranca con el nuevo modelo
- Predice mejor tus intenciones según contexto (hora, app activa, día)


📋 SISTEMA DE TAREAS (TASKWARRIOR)
═══════════════════════════════════════════════════════

- Las tareas se guardan localmente en ~/.task/
- El asistente usa el LLM para extraer fecha de frases naturales
- Un timer systemd (cada hora) verifica tareas próximas (<24h)
- Las notificaciones usan notify-send (escritorio KDE)

Comandos de terminal útiles:
  task add "descripción" due:"YYYY-MM-DD HH:MM"
  task next          → ver tareas pendientes
  task done [N]      → marcar como hecha


🗂️ PLANIFICADOR POR RECETAS
═══════════════════════════════════════════════════════

- Las recetas se guardan en ~/.jarvis/recipes.json
- Cada receta tiene: intent, steps, preconditions, recovery, inverse
- 20 recetas activas máximo
- Las no usadas en 30 días se archivan en recipes.archive.json
- Modo "aprende nueva tarea" guía al usuario paso a paso
- "deshaz lo último" revierte la última acción ejecutada
